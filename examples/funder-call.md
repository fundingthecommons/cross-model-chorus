# Fernquill Open Tools Fund: call for proposals

The Fernquill Open Tools Fund makes grants of up to USD 100,000 for open-source software that
community organizations can run themselves.

Applications must:

1. Describe the outcomes the project will achieve, not only the activities, and say how each
   will be measured.
2. Include a budget in which overhead does not exceed 10% of the total.
3. Say how the software will be maintained after the grant ends.
4. Name any matching funds and say whether they are secured or pledged.
